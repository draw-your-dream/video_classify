## 优先级 1:newref3 换强编码器补测
形象还原轴是唯一奏效的信号族,newref3 加了跨款判别余量 / 最佳视角切换 / 首帧漂移三类新量,
但只在 siglip2-base-224 下测过(死)。原始 newref 用的是 so400m,本轮权重下载受阻。
盒上带宽好,直接在盒上下 so400m 跑 `scripts/api_judge/newref3.py`
(`NR3_MODEL` 指模型名或本地快照目录,`NR3_TAG` 区分产物)。

## 优先级 2:判官第三遍
flash 单遍有 ±5pt 运行方差,现用两遍秩均值;第三遍预期 +1pt 左右,
成本约 3–5 美元/1000 条。视频已可从 S3 直接同步(路径见 RUNBOOK 第 0 节),需 GOOGLE_API_KEY。

## 优先级 3:数据侧(收益最大但要等)

(高维块直接进融合层的禁令与样本量直接相关,见 E-BLK-2 / E-FULL-1)。
