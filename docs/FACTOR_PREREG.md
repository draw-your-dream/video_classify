## 本地可跑(5090,GroundingDINO 每视频 16 帧 + SigLIP2 + OpenCV)

**F1 cap_drift** — 菌盖区域(角色框上 40%)首末帧 SigLIP2 余弦 + 颜色直方图距离。
靶:白点消融/盖形漂移/滑落吞头(64ee, 4c5f, 32da, 5155, 1f65, b729, …≥8 条)。
机制关:语料 skus 还原度 bad vs good 该因子应有分离。

**F2 anchor_min** — min over t of cos(crop_F0, crop_Ft),16 帧。
靶:纯中段漂移(a400 首末均正常的确定性反例);严格强于 first_last。
机制关:在 a400 型样本上应显著低于 first_last 型。

**F3 face_drift** — 脸部区域(角色框中带)F1 同构因子。
靶:凭空长嘴/五官增减(b729, 32da, 5155, 159a, 939c)。

**F4 size_trend** — 角色框高度随时间的趋势/极差,经背景 ORB 单应尺度补偿(排除镜头推拉混淆)。
靶:C 类(78d4, 5155, 5761, e175)。
风险:镜头运动补偿失败时误报;机制关先在有镜头推进的 good 上验证补偿有效。

**F5 nonchar_motion** — 相机运动补偿后,角色框外静物区域的残余光流能量。
靶:I 类(4f95, bd7a, 7a25, 5761)+ B 类滑移。
风险:场景里合法运动主体(人/猫)需检测剔除,否则误报;机制关在含人/宠物的 good 上校准。

## 需短租 GPU(Qwen3-VL-30B,四个定向问题轴,logit(是)−logit(否))

**F6a 悬空** — "这个毛毡玩偶此刻悬在空中/没有站在任何表面上吗?"(B 类)
**F6b 自主运动** — "画面里有没有物体在没有外力的情况下自行移动或变形?"(I 类)
**F6c 静态不可能** — "画面里是否存在物理上不可能的情形:错误的倒影、平面图画有真实深度、不可能维持的平衡?"(D 类——时间信号原理性盲区,唯一出路)
**F6d 凭空出现** — "视频中是否有物体凭空出现或消失?"(F/G 类)
对照:此前笼统问"是否违反物理规律"AUC 0.588;假设 = 定向问题显著更强。

**F7 IP 模板符合度** — prompt 内写死 IP 规范(矮胖短腿、圆头、菌盖带白点戴头顶、毛毡质感),问偏离。
靶:整段偏离型 A(15bf, 8fdc, 159a, 57 61)——首末自比对这类无效,模板写进 prompt = 无域依赖的绝对参照。
