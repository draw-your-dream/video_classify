## P1 单类 patch 异常(2026-07-30 预注册,语料机制验证先行)

**动机(第一性原理)**:身份属性(拓扑件数/部件位置/质地/配色)不可变,状态属性(姿态/视角/遮挡)自由变。
good 集合定义角色在合法变换下的"轨道",判定 = 是否落在轨道外。缺陷清单映射:
黑点/不合理嘴 = 局部纹理异常;多余肢体/尾巴 = 多余部件(good 库中无近邻);
手脚位置 = 空间关系(需位置条件化,本轮暂不做);身体过长 = 全局几何(patch 盲区,另设比例因子)。
遮挡假警的第一性消歧 = 时间持续性(真缺陷跨帧存在,遮挡只在姿态转换几帧)。

**协议(冻结,先登记后评估)**:
- 提取:16 帧,GroundingDINO 三连 prompt thr 0.25 + 方形 1.25 倍裁剪(crop_feat_original 同款),
  DINOv2-base 518×518 patch tokens(37×37×768),前景 = patch 中心落在检测框内。
- 划分:语料 good 455 以 seed=0 置换,前 300 建库 / 后 155 评估;bad_huanyuandu 464 全评。泄漏隔离。
- 库:bank-good 检出帧前景 patch,每视频至多 1300(md5(rel) 种子确定性子采样)。
- 打分:patch 异常 = 1 − max cos sim(1-NN);帧分 = 前景 top-1%/5% 均值;
  视频分 = 帧分 max / p75 / mean(p75 = 持续性口径)。
- 主指标:bad vs eval-good AUC(fg 口径);bg 口径仅对照。
- **晋级关**:AUC ≥ 0.70 且 fg > bg 口径 → 允许迁移 prod500(库改用 prod good 重建,阈值走分位协议,
  n=27 上不调任何超参);不达标 → 记录后归档,不进门。
- 已知盲区:身体过长/比例类(patch 局部正常)——若语料 bad 中该类占比高,AUC 上限受压,分错误类复盘。

脚本:`extract_patch_feat.py`(特征)/ `patch_bank_eval.py`(建库+打分+AUC)。

### P1 v2 修订(2026-07-30,业界调研后,运行前冻结)

调研依据(要点):
- **AnomalyDINO(WACV'25)**:DINOv2 patch + 1-NN 记忆库为少样本工业检测 SOTA(MVTec 1-shot 96.6 AUROC);
  图级分 = **top-1% patch 距离均值**(tail-value-at-risk),余弦距离——与本协议帧分口径一致,予以保留;
  其 PCA 前景掩码在"对象占画面 ≥50%(close-up)"时失效——我们的裁剪即 close-up,
  故弃 PCA 掩码,用检测框前景掩码(本协议原设计),此为有据取舍。
- **MVTec LOCO / CSAD(BMVC'24)**:缺陷分结构性(纹理/污染)与逻辑性(多余/缺失部件、数量、位置)两类,
  patch-kNN 只覆盖结构性;CSAD 用组件分割+patch 直方图补逻辑性(LOCO 95.3)。
  本轮增设 **s_hist 直方图分支**(bank patch 球面 k-means k=64,帧前景聚类占比 1-NN L1)
  作为逻辑异常的简化探针,靶多余肢体/部件占比失衡。
- **VBench(CVPR'24)**:subject consistency 即用 DINO 特征跨帧余弦——DINO 系对"同类个体差异"敏感,
  适合形象还原判定,支持本轮骨干选择。

修订清单:
1. good 划分改**款分层**(每款按 300/455 比例进库,防某款缺席库导致整款评估误报);seed 确定性不变。
2. 增设 s_hist 逻辑异常分支(同样三口径聚合),与结构分支同表评估。
3. 增加**裁剪对象核验**步骤(verify_crops.py):so400m 零样本分类裁剪(蘑菇角色 vs 4 干扰类),
   win_rate<0.5 进 flag 清单人工复核;并出 款x标签 蒙太奇大图供人工过目——核验不过的视频不参与结论。
4. 晋级关不变:AUC >= 0.70 且 fg > bg;s_hist 单独看,不与结构分支合并调参。

### P1 判决(2026-07-30 深夜,语料 919 机制验证完成)

**未过晋级关,归档不进门。** 全口径 AUC 表(bad 464 vs eval-good 156,款分层划分,泄漏隔离):
最好 s_hist_mean=0.568,结构分支最好 s_top5_fg_mean=0.543;fg 全面>bg(方向对,幅度不足);
剔除跑偏裁剪敏感性三档 0.564–0.571,判决稳健。

**失败机理(核心产出)**:bank_good 分数 P50=0.19 vs eval_good P50=0.42——
开放内容域中每条新视频自带合法新内容(道具/场景/配饰),novelty 噪声地板(0.42)
淹没缺陷信号(bad P50=0.424)。MVTec 范式的封闭场景前提在本域不成立。

**分款分库对照**:池化 0.574(vs 全局库 0.568),款级收紧无效——噪声在款内。
个别款样本小、方差大(花花 top1_fg 0.911@n_good=12,冰晶 hist 0.750,甜品 hist 0.373 反向),不过度解读。
推论:参照系必须收紧到"本视频自身"——**i2v 首帧原图升为头号数据请求**
(自参照 dense 匹配,理论上消灭 novelty 地板)。

**候选因子登记 P2 = 角色在场性(1 − cos_centroid)**:视频前景嵌入到全体中心的余弦,
语料域内单轴 AUC 0.584,专抓角色缺席/被道具顶替;prod500 可用现存裁剪特征直接复算,待预注册评估。
